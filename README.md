# 📋 WPF Student Registry

Small WPF practice application: add, edit and remove student records (name, surname, number) in a list view.

![C#](https://img.shields.io/badge/C%23-512BD4?style=flat-square&logo=dotnet&logoColor=white)
![WPF](https://img.shields.io/badge/WPF-.NET_6-512BD4?style=flat-square)

## 🚀 Running

Open `StudentRegistry.sln` in Visual Studio 2022 (.NET 6 desktop workload) and run.
